# ☕ August Cafe – Local Business Website

A modern and responsive café website created as part of the **Future Interns Full Stack Web Development Internship – Task 3**.

The website presents August Cafe as a welcoming café, deli, bakery and patisserie in Andheri West, Mumbai, with sections for its menu, cafe experience, gallery, customer experience and contact information.

---

## 🌿 About the Project

The goal of this project is to create a professional online presence for a local café.

The website is designed to help a café:

- Present its business professionally online
- Showcase its food and beverages
- Provide important location and contact information
- Give visitors an attractive visual experience
- Make it easier for customers to explore the business
- Provide a simple enquiry/contact section

---

## ✨ Features

- Responsive navigation bar
- Hero section with café branding
- About section
- Menu section
- Cafe experience/features section
- Image gallery
- Customer experience section
- Contact and location information
- Contact form with interactive response
- Responsive design for desktop and mobile screens

## 🎨 Website Sections

### Home
Introduces August Cafe with a welcoming hero section and navigation buttons.

### About
Provides an overview of the cafe and its food and beverage experience.

### Menu
Highlights selected food and beverage categories.

### Gallery
Displays attractive cafe and food-related visuals.

### Customer Experience
Provides a section for showcasing visitor feedback.

### Contact
Displays the business location, phone number, opening hours and an enquiry form.

---

## 📱 Responsive Design

The website is designed to work across:

- Desktop
- Laptop
- Tablet
- Mobile devices

The navigation and content layout automatically adapt to smaller screens.

---

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Run the website using VS Code Live Server or open `index.html` directly in a browser.
